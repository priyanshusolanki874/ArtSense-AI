# 🎨 ArtSense AI

An AI-powered web application that analyzes artworks and provides intelligent feedback using AI. Users can upload their paintings or sketches, receive an AI-generated score, discover strengths and weaknesses, and get personalized suggestions to improve their artwork.

---

## ✨ Features

- 🔐 User Authentication (Register/Login/Logout)
- 🎨 Upload Artwork
- 🤖 AI-Powered Artwork Analysis
- 📊 AI Score Generation (0–100)
- ✅ Artwork Strengths
- ❌ Artwork Weaknesses
- 💡 Improvement Suggestions
- 🖼️ Personal Artwork Gallery
- ✏️ Edit Uploaded Artwork
- 🗑️ Delete Artwork
- 📩 Contact Form
- 📱 Responsive User Interface

---

## 🤖 AI Analysis

After uploading an artwork, ArtSense AI analyzes the image and generates:

- 🎯 Overall AI Score
- ✅ Strengths
- ❌ Weaknesses
- 💡 Personalized Suggestions

This helps artists understand the quality of their artwork and identify areas for improvement.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/priyanshusolanki874/ArtSense-AI.git
```

### Move into the project directory

```bash
cd ArtSense-AI
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run migrations

```bash
python manage.py migrate
```

### Start the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
